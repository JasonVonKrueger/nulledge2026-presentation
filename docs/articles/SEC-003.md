# SEC-003: Client-callable Script Include queries without ACLs

**Blocks completion** (priority 1).

## What it means

A **client-callable** Script Include creates a `GlideRecord` or `GlideAggregate`. Those classes ignore ACLs, and a client-callable Script Include can be called by **any logged-in user** from their browser.

## Why it matters

A caller can pass any parameters they like. With GlideRecord, they can read or change records their ACLs would normally hide.

## How to fix it

Use `GlideRecordSecure`, which enforces ACLs for the calling user:

```javascript
getEmail: function() {
    var user = new GlideRecordSecure('sys_user');
    if (user.get(this.getParameter('sysparm_user_id'))) {
        return user.getValue('email');
    }
    return '';
}
```

If you need GlideRecord, check access explicitly with `canRead()` or `canWrite()` before returning or changing anything, and validate every `sysparm_` parameter.

## Not reported

- GlideRecordSecure.
- A GlideRecord that is checked with `canRead()`, `canWrite()`, `canCreate()` or `canDelete()`.
- Script Includes that aren't client callable.
