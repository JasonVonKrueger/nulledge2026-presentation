# SEC-002: Dynamic code execution

**Blocks completion** (priority 1).

## What it means

The script builds code from text and runs it:

- `eval()`;
- `new Function()`;
- `setTimeout()` / `setInterval()` given a string;
- `GlideEvaluator.evaluateString()`.

## Why it matters

If any part of that text comes from user input, an attacker can run their own code with the script's privileges. Code built from strings also can't be reviewed or debugged.

## How to fix it

| Instead of | Use |
|---|---|
| `eval(jsonText)` | `JSON.parse(jsonText)` |
| `setTimeout('refresh()', 100)` | `setTimeout(refresh, 100)` |
| `eval('helper.' + name + '()')` | call the function directly, or use a lookup object |
| running a script stored in a field | `new GlideScopedEvaluator().evaluateScript(record, 'field')` |
