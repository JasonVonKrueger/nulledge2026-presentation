# JS-001: Debug statements left in code

**Reported to the reviewer; does not block** (priority 3).

## What it means

The script contains debug output that looks like it was left behind:

- `gs.print()`;
- `console.log()`, `console.debug()` or `console.trace()`;
- `jslog()` or `alert()`;
- `gs.addInfoMessage()` with a message starting "debug", "test", "todo" and so on.

## How to fix it

Remove it. For logging that should stay, use `gs.info()`, `gs.warn()`, `gs.error()` or `gs.debug()` with enough context to be useful.

## Not reported

`gs.log()`, which is the standard logging call in global scope.
