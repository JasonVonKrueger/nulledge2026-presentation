# JS-003: Deprecated JSON API

**Reported to the reviewer; does not block** (priority 3).

## What it means

The script uses an old JSON API: `new JSON().encode()` / `decode()`, `.evalJSON()`, `Object.toJSON()` or `new JSONParser()`.

## How to fix it

Use native JSON:

```javascript
var text = JSON.stringify(obj);   // instead of new JSON().encode(obj)
var obj = JSON.parse(text);       // instead of new JSON().decode(text)
```
