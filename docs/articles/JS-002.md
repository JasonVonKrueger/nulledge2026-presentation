# JS-002: Accidental global variable

**Reported to the reviewer; does not block** (priority 3).

## What it means

A variable is assigned without ever being declared with `var`, so it becomes a **global** variable, shared with every other script in the same transaction.

```javascript
for (i = 0; i < list.length; i++) {   // i is global
    total = total + list[i];           // so is total
}
```

## Why it matters

Two scripts using the same undeclared name, often `i`, overwrite each other's values. The bugs that follow are rare and very hard to trace.

## How to fix it

Declare it:

```javascript
var total = 0;
for (var i = 0; i < list.length; i++) {
    total = total + list[i];
}
```

## Not reported

Platform variables a script is meant to set, such as `answer`, `current` and `g_scratchpad`. Administrators can add names in `ecs.js.assignable_globals`.
