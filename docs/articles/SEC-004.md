# SEC-004: Credentials set in script with setBasicAuth()

**Blocks completion** (priority 2).

## What it means

A REST or SOAP message gets its user name and password from script through `setBasicAuth()`, even if they are read from a property.

## Why it matters

Credentials handled in script are easy to log by accident, and rotating them means touching code.

## How to fix it

Configure authentication on the message instead:

- a **Basic Auth profile** on the REST Message; or
- a **Connection & Credential alias**.

```javascript
var request = new sn_ws.RESTMessageV2('Vendor API', 'get');
request.setAuthenticationProfile('basic', profileSysId);
```

## Not reported

A literal password in `setBasicAuth()` is reported by SEC-001 at the higher priority instead.
