# JS-004: Empty or swallowing catch block

**Reported to the reviewer; does not block** (priority 3).

## What it means

A `catch` block either is empty, or never looks at the error and doesn't rethrow it. The failure disappears without a trace.

```javascript
try {
    importRecords();
} catch (e) {
    // nothing
}
```

## Why it matters

The script carries on as if nothing failed. Data ends up wrong, and nobody can tell why.

## How to fix it

Do something with the error: log it with context, rethrow it, or return a clear failure.

```javascript
try {
    importRecords();
} catch (e) {
    gs.error('Vendor import failed for batch ' + batchId + ': ' + e);
    throw e;
}
```

## When it is intentional

If ignoring the error really is right, say why in a comment, and tell your reviewer.
